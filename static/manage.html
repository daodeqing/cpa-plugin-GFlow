Supported models and API usage

All models use the same port as the current EasyCLIProxyAPI core (default 8317). No extra port is needed. Send standard OpenAI or Gemini requests directly to http://127.0.0.1:8317.

OpenAI-compatible text-to-image example:

curl -X POST "http://127.0.0.1:8317/v1/chat/completions" \
  -H "Authorization: Bearer YOUR_CPA_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gflow-nano-banana-2.1",
    "messages": [{"role": "user", "content": "A cute cyberpunk kitten"}],
    "stream": true
  }'

OpenAI-compatible text-to-video example (Veo 3.1):

curl -X POST "http://127.0.0.1:8317/v1/chat/completions" \
  -H "Authorization: Bearer YOUR_CPA_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gflow-veo-3.1-fast",
    "messages": [{"role": "user", "content": "Aerial view of golden sunlight on gentle ocean waves"}],
    "stream": true
  }'

Method 1: One-click sync with the browser helper (recommended) Free extension

Extension source on GitHub: https://github.com/daodeqing/cpa-plugin-GFlow/tree/main/browser-extension

  1. Download and load the extension: Open the copied download URL in the browser address bar and extract the archive. Enable Developer mode at chrome://extensions/ and click Load unpacked.
  2. Paste config: Click Copy extension config above, paste it into Quick import in the extension popup to fill the API URL and credentials, and enter the current Google account email.
  3. One-click sync: Log in to flow.google.com in the same browser and click Save and sync now in the extension. It activates the session and submits credentials in the background.

What is this? View details

This free Chrome / Edge browser helper automatically syncs Cookies from a logged-in Flow session. It is separate from the EasyCPA plugin.

The EasyCPA embedded window restricts direct downloads. Paste the URL into the browser address bar to download.

Settings are saved only in this Chrome extension. Do not share management credentials.

Method 2: Paste manually
How do I get a Cookie / Session Token?
  1. Log in to Google Flow, press F12, open Network, select Disable cache, then refresh.
  2. Select a request to the current Flow website, copy the Cookie value under Headers, Request Headers, and paste it above.

If you see Provisional headers, select a completed request. Do not copy Set-Cookie. If __Secure-next-auth.session-token exists under Application, Cookies, you can copy only its Value; otherwise use the extension.

Accepts Cookie strings, Cookie JSON, or a Session Token. Sync again after login expires. Do not share Cookies.

Sync only accounts you are authorized to use. Adding an account verifies login, checks credits, and may create a project, without generating anything. Flow credits and captcha fees cost extra.
